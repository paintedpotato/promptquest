# Prompt Quest 🎮

An interactive storytelling game that teaches teenagers the fundamentals of prompt engineering through engaging challenges and narrative gameplay.

## About

Prompt Quest follows the story of ARIA, an AI character who needs help completing tasks. Players learn to craft effective prompts by:
- Being clear and specific
- Specifying output formats
- Assigning roles and personas
- Combining multiple techniques for complex requests

## How to Deploy to GitHub Pages

### Step 1: Create a GitHub Repository
1. Go to [GitHub](https://github.com) and create a new repository
2. Name it something like `prompt-quest`
3. Make it public
4. Don't initialize with README (we already have files)

### Step 2: Upload Files
1. Upload these files to your repository:
   - `index.html`
   - `prompt_quest.js`
   - `README.md`

### Step 3: Enable GitHub Pages
1. Go to your repository Settings
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Choose the `main` branch and `/ (root)` folder
5. Click Save

### Step 4: Access Your Game
After a few minutes, your game will be live at:
```
https://[your-username].github.io/[repository-name]/
```

## Local Testing

To test locally before deploying:
1. Simply open `index.html` in your web browser
2. The game should work immediately (requires internet for CDN libraries)
